# Projeto Final - José Luteano

## Descrição
O objetivo é criar um sistema simples de validação de pedidos,
onde verificamos se um pedido está correto antes de ser aceito.

## O que o projeto faz?
- Valida se o pedido tem nome, produto e quantidade
- Verifica se a quantidade é maior que zero
- Retorna uma mensagem de erro se algo estiver errado
- Retorna uma mensagem de sucesso se o pedido estiver correto

## Tecnologias usadas
- Node.js (para rodar os testes)
- GitHub Actions (para testar automaticamente)

## Como executar o projeto

Você precisa ter o Node.js instalado no seu computador.
Não precisa ser no Visual Studio Code, pode ser em qualquer terminal
que tenha Node.
